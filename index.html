Spotify Recommender

EDA · Item/User-based · SVD · Content-based

Built hybrid recsys and explained trade-offs (precision/novelty/coverage) with clear metrics and slices.

Repo: github.com/aidafuva/spotify-recommender ↗

Logline → Problem → Approach → Impact → Tools
  • Logline: Turn listening history into relevant, explorable recs.
  • Problem: Baseline popularity skews; cold-start on niche tracks; explainability.
  • Approach: EDA → CF (user/item-based), SVD, content-based fallback; metric deck (RMSE, MAP@K, coverage/novelty); error analysis by cohort.

A/B Testing: Facebook vs AdWords — Live Dashboard

Campaign Analysis · Incrementality · Causal Measurement · Tableau

Interactive dashboard comparing conversions, conversion rate, and cost-per-click across two paid channels. Click any data point to filter all charts simultaneously.

Logline → Problem → Approach → Impact → Tools
  • Logline: Which paid channel deserves more budget?
  • Problem: Facebook and AdWords run simultaneously — unclear which drives incremental value vs. baseline volume.
  • Approach: A/B comparison across conversions, conversion rate, and CPC over time; interactive filters by year to isolate performance periods.
  • Impact: Facebook generates 2x more conversions at similar CPC — suggesting superior reach, not efficiency. Actionable budget reallocation signal.
  • Tools: Tableau Public (dual-axis charts, interactive dashboard filters).
